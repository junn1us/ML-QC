# ML-QC
A repository for people who see a 99% training accuracy and immediately become suspicious.
A collection of statistical modeling, machine learning, and quality-control experiments—because “the process has always done that” is not an acceptable root-cause analysis.
Here, p-values are interrogated, models are cross-validated, and observations beyond three sigma are politely asked to explain themselves.
Random forest cannot save a process that was never in control.
Turning noisy process data into control charts, predictive models, and increasingly sophisticated evidence that the production line is haunted.
